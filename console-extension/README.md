# Console 实时日志采集（Chrome 插件）

只是一个 Chrome 插件，不需要起本地服务、不需要双击任何启动脚本、不需要额外打开网页。
点插件图标打开侧边栏，开始/停止/实时查看/落盘全部在侧边栏里完成。

## 安装（一次性）

1. 打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录 `console-extension/`

## 日常使用

1. 切到你要监控的标签页（比如 Cocos 游戏页面），把它设为当前激活标签页
2. 点浏览器工具栏上的插件图标 → 直接打开右侧侧边栏（不是小弹窗）
3. 点侧边栏里的「开始」：
   - 第一次会弹出一次文件夹选择框，选一个你想存日志的目录；之后会记住这个目录，下次打开侧边栏也不用重新选
   - 之后日志会实时显示在侧边栏里，同时实时写入该目录下一个新生成的 `console-log-<时间戳>.txt` 文件
   - 想换一个保存目录，随时点「更换目录」重新选择（采集中不能换，需要先「停止」）
4. 可以正常切换到其他标签页操作，侧边栏仍然只记录你点「开始」时锁定的那个目标标签页
5. 点「停止」结束采集并收尾文件；也可以直接关闭目标标签页，会自动停止并收尾
6. 「清空视图」只清空侧边栏里显示的部分，不影响已经写到硬盘的文件内容、也不影响下面的统计数字和错误汇总
7. 顶部有一排统计条（Errors / Warnings / Info / Verbose 各自的累计条数），点一下某个数字可以一键把筛选切到只看这个级别
8. 「◀ 上一个错误」「下一个错误 ▶」按钮可以在当前显示的日志里直接跳转定位，不用自己拿眼睛扫；没有错误时按钮是禁用状态
9. 点「停止」时，如果这次采集里出现过 Errors，会额外生成一份 `console-log-<时间戳>-errors.txt`，只包含这次采集里所有 Errors（不含 Info/Warning 等），方便直接把这个小文件发给开发定位问题，不用甩一整份大日志过去

## 说明

- 侧边栏里的实时视图最多展示最近 5000 行（避免面板本身卡死），但硬盘上的文件是完整不限行数的
- 未勾选/关闭侧边栏不会导致文件丢失：会尽量在关闭前把文件写完整，但仍建议采集结束后主动点一次「停止」
- 顶部有一个类似 DevTools 的级别筛选下拉框（Verbose / Info / Warnings / Errors），可以勾选/取消勾选来控制侧边栏里显示哪些级别
- 搜索框可以按关键字实时过滤当前显示的日志
- 「合并重复日志」勾选后，连续出现的相同日志会合并成一行并标注次数（如 `(×12)`），默认不勾选（逐条显示）
- 日志区按级别自动配色：Errors 红色、Warnings 黄色、Info 默认色、Verbose 灰色
- 手动往上滚动查看历史时会暂停自动滚动，滚回底部或点右下角「↓ 回到底部」按钮恢复
- 顶部统计条上的 Errors/Warnings/Info/Verbose 计数是**本次采集从「开始」起的累计总数**，「清空视图」不会清零它们，只有重新点「开始」才会清零重新计数
- 以上筛选/搜索/合并/配色/统计**只影响侧边栏显示**，硬盘上的文件始终按原始顺序记录全部日志，不受这些设置影响
- 每次在 `chrome://extensions` 重新加载/更新插件后，需要刷新一下目标页面再点「开始」，否则旧的注入脚本会因为扩展上下文失效而无法正常工作
